# 🎯 AI-Powered Job Application Assistant

A smart tool that helps job seekers optimize their applications using ML and AI.

## ✨ Features

- 📊 **Resume Match Scorer** — TF-IDF + Cosine Similarity ML model
- 🔍 **Skill Gap Detector** — Find missing skills with learning resources
- 🤖 **ATS Keyword Analyzer** — Beat applicant tracking systems
- 📝 **Cover Letter Generator** — AI-written tailored cover letters

## 🛠️ Tech Stack

- Python, Scikit-learn, NLTK, spaCy
- Groq API (LLaMA 3.3)
- Streamlit
- PyMuPDF

## 🚀 How to Run Locally

pip install -r requirements.txt
streamlit run app.py
